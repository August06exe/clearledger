实测揪出并修复 3 个真前端 bug：

1. **状态词汇不统一**：后端给模型节点的状态是 dbt 词汇（success/pass），给源节点的是灯色词汇（green/red），前端映射表缺 green/yellow/red 键 → 图上大量节点错误显示灰色。→ 在 `/api/lineage/graph` 统一归一化为灯色词汇。
2. **G6 fitView 时序**：fitView 在布局落地前执行，血缘图被放大 411% 只见一个节点。→ 改为 afterlayout 事件后再适配视图。
3. **静态资源缓存**：升级 JS 后浏览器仍用旧缓存（对单人用户日后升级是隐患）。→ index.html 给全部静态资源加版本号参数（升级时改一处版本串即可）。

另：暴露 `window.__clGraph` 调试句柄（控制台可直接检查图实例，方便 AI 运维）。
