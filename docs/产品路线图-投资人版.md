> 状态：🚧 抢鲜体验（Early Access）

## 一句话定位

把公司管理报表的生产，从"多人接力的人工流水线"升级为"AI 生产、自动运转的数据流水线"——数据从哪来、怎么加工、被谁使用，全程可追溯；一个入口看所有报表和数据的实时状态。

## 我们解决什么问题

传统管理报表的生产链路：业务系统导出 → 人工 Excel 加工 → 多轮传递 → 人工拼装成报表。痛点：

- **慢**：每个环节都是人工节点，出数周期以天计
- **黑盒**：口径藏在某个人脑里，"这个数怎么算的"没人说得清
- **脆弱**：一个人休假或离职，报表就断供
- **不可信**：数据出错了往往几天后才发现，且难以追责到环节

## 产品理念

1. **AI 生产、人审核**：管道代码、数据字典、清洗规则由 AI 生成，人只定义口径并把关
2. **一切皆代码**：报表逻辑、清洗规则全部进 Git，可版本、可回滚、可审计
3. **血缘与字典是副产品**：管道每跑一次，血缘图和数据字典自动保持最新，不再是会烂掉的文档
4. **红绿灯治理**：数据异常自动亮灯、自动归因，错误数据不流进报表

## 技术底座（一页看懂）

```
Excel/CSV 接入 → DuckDB 分析引擎 → dbt 转换管道（三层）→ 一体化门户
                                       ↑                  ↑
                              AI 聊天式接入 / 字典生成    血缘图 · 红绿灯 · 报表
```

全开源技术栈（DuckDB / dbt / React / FastAPI），单机私有化部署，数据不出内网，未来可平滑迁移至云上。

## 各版本详情

### v0.1「第一桶数据」——先让数据流起来
- Excel/CSV 约定目录接入，自动识别并入库（DuckDB）
- dbt 三层管道（原始层 → 加工层 → 报表层）+ 数据质量测试门禁
- 首批 3 张标杆管理报表端到端跑通
- 跑批状态灯：🟢 成功 / 🔴 失败（失败自动拦截下游，报表标记"数据过期"而非展示旧数）
- **上线标志**：一张报表从"人工半天"变成"机器 10 分钟自动出数"

### v0.2「看得见」——一体化门户 V1
- 数据血缘蜘蛛网图：表级血缘，点击下钻到字段级
- 红绿灯升级：🟡 数据质量告警（跑通了但数据有异常）
- 数据字典页面：AI 辅助撰写、随管道自动更新
- 报表页 + Excel 一键导出
- **上线标志**：管理层只靠这一个入口看数，不再索要 Excel

### v0.3「AI 工厂」——AI 生产与维护闭环
- AI 生产维护体系：数据接入、字典撰写、异常归因、报错修复全部由 AI 完成，成果进 Git、状态进门户，人不碰代码
- 快速接入：新数据源从文件到出数 < 15 分钟（AI 自动体检 → 生成建表、字典、测试草稿 → 人确认）
- 字典自动成稿：字段含义、口径说明随管道更新自动重写
- 异常归因报告：黄灯/红灯出现自动生成"发生了什么、可能为什么、建议动作"
- **上线标志**：新增一个数据源的人工操作 < 15 分钟

### v0.4「口径引擎」——把"算法"管起来
- 指标中心（语义层）：每个指标只允许一个定义处，所有报表引用指标而非各自写 SQL
- 复杂规则引擎化：费用分摊、口径调整、组织变动后的历史重算（具体范围以专项评审为准）
- 自动对账：新系统与老口径自动比对，差异自动解释
- **上线标志**：指标口径变更从"改 N 张表"变成"改 1 处定义"

### v1.0「正式版」——老 Excel 退役
- 细粒度权限：谁可以看哪张报表、哪个指标
- 20 张报表全量迁移完成，人工 Excel 加工节点清零
- 一键备份/恢复，运维手册 + AI 运维助手
- **上线标志**：连续 30 天 T+1 08:30 前自动出数，0 人工介入

### v1.x 长期运营（正式版后持续更新）
- 🤖 **门户内嵌 AI 助手**：面向财务客户的产品化能力——对话式接数据、问数、归因（接入大模型 API）
- 🗣 **自然语言问数**："上季度华东毛利为什么跌了？"直接问；走指标中心，安全可控
- 📮 **定时推送**：钉钉/企微/邮件日报
- 🔌 **更多数据源**：业务 API 接入、CDC 增量同步
- ☁️ **云原生**：迁云部署、开发/生产多环境
- 📈 **智能预警升级**：指标异常自动检测，不依赖人工设阈值
- 📦 **远期构想**：整套底座产品化，输出给同类公司

## 风险与对策

| 风险 | 对策 |
|------|------|
| 单人 + AI 维护的运维风险 | 极简架构（单机 2 容器）、一键备份恢复、AI 排障助手 |
| 业务口径复杂多变 | 口径集中到指标中心、自动对账兜底、复杂规则专项评审 |
| 数据安全 | 全程私有化部署；AI 功能默认只传表结构、不传业务明细；可选本地大模型 |
| AI 生成代码的质量 | 测试门禁 + Git 评审 + 灰度上线，测试不过数据不发布 |
| 开源依赖风险 | 只用主流标准栈（DuckDB/dbt/React），保持可替换性 |

## 成功指标（KPI）

- 报表生产人工节点：**N 个 → 0 个**
- 出数时效：T+1 08:30 前达成率 **≥ 99%**
- 新报表上线周期：**以周计 → 以天计**
- 数据异常：发现时间从"几天后" → **当天亮灯 + 自动归因**
