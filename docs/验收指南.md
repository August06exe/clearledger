# 晨间验收指南（2026-09-19 早）

> 今晚 develop 分支上交付了 v0.1「第一桶数据」+ v0.2「看得见」的大部分内容。
> 本文档 5 分钟能走完一遍核心验收，最后是合并 main 的建议。

## 一、启动（2 分钟）

1. 双击根目录 **`启动明账.bat`**（环境今晚已装好，应秒开；浏览器自动打开 http://127.0.0.1:8620）
2. 若想从头看一遍完整流程：双击 **`重建演示数据.bat`**，然后刷新浏览器

## 二、五个页面逐个看（3 分钟）

| 页面 | 看什么 | 应该看到 |
|------|--------|----------|
| **总览** | 顶部红绿灯、4 张 KPI 卡、两张走势图、管道节点状态 | 黄灯（这是**故意的**：演示数据埋了 2026-05 华东收入骤降，触发"环比骤降>50%"告警测试）；KPI 是最新完整月 |
| **数据血缘** | 蜘蛛网图；点击 `mart_region_month` | 依赖从左（源数据）流向右（报表层）；右侧面板有该表的**字段级血缘**（每个字段 ← 上游哪个字段）；告警节点黄色描边；**源节点绿/红来自摄取结果** |
| **数据字典** | 点 `stg_customers`、`mart_kpi_monthly` | 每个字段都有中文业务含义（AI 撰写）；搜索"毛利"能跨表搜到字段 |
| **管理报表** | 经营月报 → 区域月报 → 客户汇总 → 导出 Excel | 图表 + 明细可切换参数筛选；导出的 Excel 表头是中文且数字格式化 |
| **跑批历史** | 点开最近一次运行 | 摄取留痕（每个源文件进了多少行）、55 个节点逐一状态、失败会有信息、日志末尾 400 行 |

## 三、必测的两个交互（2 分钟）

1. **手动跑批**：右上角"▶ 立即跑批"→ 按钮变"跑批中…" → 几秒后自动恢复并刷新数据
2. **红灯演示**（可选）：把 `data/inbox/sales_transactions.csv` 临时改名 → 跑批 → 总览变红、
   报表页提示数据未就绪；改回名字再跑批恢复。**红 = 摄取失败，下游被拦截，绝不拿旧数装没事。**
