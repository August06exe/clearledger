# semantic/ —— 引擎

数据加工流水线本体。零业务预设：不认识"销售额"，只认账套配置里写的口径。换一家公司＝换一套 yml 配方，这个目录一行不改——这是本项目的第一性设计。

| 文件 | 职责 |
| --- | --- |
| loader.py | 读六份 yml 配方并交叉校验（改配置后先过它） |
| ingest_run.py | 收货验收：投放区文件过三道契约，违规进挂起队列 |
| compile_dbt.py | 把 yml 翻译成 dbt 工程（instances/*/pipeline 是它的产物，禁手改） |
| query.py | 查报表，只许读 marts 成品层 |
| harvest.py | 把人工裁决的匹配结果沉淀回档案 |
| inspect.py | 装配线体检：新账套接入前的全面检查 |

这个目录的任何改动都要走 PR + 评审，是全仓最重的事故区。
